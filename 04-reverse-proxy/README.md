# 第四章：反代（反向代理）

本章节用于存储 AI 接口与网页端反向代理、API 聚合分发及中转服务的搭建教程。

## 核心内容规划

1. **轻量级无服务器反代**
   - 使用 Cloudflare Workers / Pages 搭建免费 API 反代
   - 自定义域名绑定与路由配置
2. **服务器自建反代（Nginx / Caddy）**
   - Nginx 反向代理配置（支持 SSE 流式输出优化）
   - SSL 证书自动申请与续期
3. **AI 渠道聚合与分发管理（One API / New API 等）**
   - Docker 一键部署多渠道聚合网关
   - 多账号号池轮询、负载均衡与令牌（Token）额度分发
   - Web 端共享反代方案（Pandora / 镜像站部署）
