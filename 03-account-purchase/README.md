# 第三章：卡网购买账号

本章节用于存储通过第三方发卡网（卡网）购买成品账号、API 额度及安全验号的相关信息。

## 核心内容规划

1. **卡网渠道甄别与选购指南**
   - 常见账号类型区分：独享号、共享号、成品号、初始号、API Key 令牌
   - 渠道防坑指南与质保规则确认
2. **账号交接与安全加固**
   - 登录前的 IP 与浏览器环境匹配
   - 辅助邮箱修改、密码重置流程
   - 双重验证（2FA / TOTP 密钥）绑定与备份
3. **异常售后与日常维护**
   - 账号风控触发点与规避方法
   - 批量账号管理工具推荐
