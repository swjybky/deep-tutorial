1. **主流 AI 聊天客户端接入**

2. **AI 辅助编程与 IDE 接入**

3. **代码与业务系统 SDK 接入**
   - OpenAI / Anthropic / Gemini 兼容格式 SDK 调用示例（Python / Node.js）
   - 常见报错码（401 / 403 / 429 / 502）排查指南
